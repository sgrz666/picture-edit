# FreeMan 数据集适配性评估与使用方案

日期：2026-10-04。撰写依据：论文全文（arXiv 2309.05073v4，含表 1 数据集对比与附录）、官方文档页（wangjiongw.github.io/freeman/documents.html）、HF 仓库目录树（wjwow/FreeMan，57 文件 829GB，树公开、文件门控）、GitHub 仓库（wangjiongw/freeman）。所有数字均来自上述一手来源；少数明确标注"推断"的除外。本轮未取得数据包，训练收益未实测。

---

## 1. 数据集介绍

**定位**：首个大规模"真实日常场景 + 多视角 + 官方 SMPL 标注"的人体动作数据集，为 3D 人体姿态估计设计（CC BY-NC 4.0，仅限研究）。

**规模**：40 名被摄者 × 123 类统一动作 × 10 类场景 = 8000 条序列、1130 万帧（1000 万帧@30FPS + 130 万帧@60FPS）。每 session 由 **8 台可移动的同步智能手机**拍摄，1920×1080。

- **场景（10 类，4 室内 6 室外）**：Sport Court / Corridor / Lobby / Library / Dance Room / Park / Cafe / Platform / Courtyard / Square。动作带真实物体交互（咖啡厅喝水、图书馆看书），官方明确"让数据尽量接近真实世界"。
- **被摄者**：40 名志愿者来自港中深（CUHK-SZ）及其舞蹈俱乐部（MaxDancingClub），其中 **22 人为受训舞者**（承担舞蹈动作）。亚裔为主（官方未给国籍统计，此条为样图目检结论）。
- **人物尺寸**：官方明确 bbox 面积占全图 **0.01 ~ 0.7**，即人物高度约 100px ~ 900px 波动。

**官方标注（HF 实测目录树）**：

| 内容 | 格式 | 说明 |
|---|---|---|
| RGB 视频 | MP4 1920×1080 | 按 `yyyymmdd_sessionuuid_subjNN` 组织，每 session 8 相机（c01–c08），30/60FPS 两子集 |
| SMPL 参数 | `.npy`，`[F, 85]`，**每视角一份** | ⚠️ 仅 SMPL：无手部（15×3）、无脸部（jaw/表情）参数 |
| 2D 关键点 | `.npy`，COCO 17 关节，`[C, F, J, 2]` | 非 DWPose 布局 |
| 3D 关键点 | `.npy`，`[F, 17, 3]` | |
| 2D bbox | `.npy` | 可直接用于人物像素高度筛选与裁剪 |
| 相机标定 | JSON（针孔：内参/外参/畸变，OpenCV 约定）+ `chessboard.pkl` | 每场棋盘格标定 |
| 划分 | train/valid/test.txt + `ignore_list.txt`（官方剔除序列）+ `session_list_mono.txt`（单目 session） | |

**官方没有**：SMPL-X、DWPose、人物 mask、depth、normal、parsing、逐帧接触标注、跨人配对。

**获取方式（2026-10-04 实测）**：签数据使用协议 → 填表（Google：forms.gle/XN3UE6ZqPYyQG76Y7，或腾讯：wj.qq.com/s2/13036236/c8c5/）→ 在 HF（wjwow/FreeMan）或 OpenXLab（wangjiongwow/FreeMan）申请权限，2~3 个工作日。目录树匿名可列（829GB，按人分 zip，单包 5~43GB；标注包 keypoints2d 2GB / keypoints3d 1.3GB / motions 1.6GB / cameras 0.9MB），**文件本体匿名 403 门控**。获批后建议先下 `subj05.zip`（5.5GB，最小包之一）验证质量。

## 2. 数据集适配性

### 2.1 对本项目 A/B/C 契约的逐项判定

| 需求 | FreeMan 现状 |
|---|---|
| 日常真实图片 | ✅ 最强项：10 类日常场景实拍，8 机位同摄，真实光影/物体交互 |
| 亚洲人为主 | ✅（目检推定）港中深招募，样图全亚裔；无官方统计，获批后需人工清点 |
| RGB_A | ✅ 官方 |
| DWPose_A | ❌ 自补（管线现成：add/tools DWPose） |
| SMPL-X_A | ❌ 仅 SMPL[85]，手/脸缺失 → 自行升级拟合（SMPLest-X，SMPL 可作初始化） |
| Depth / Normal / Mask / Parsing | ❌ 全部自补（Sapiens + SAM2 现成） |
| B：异人同动作 | ✅ **类别级成立**：123 类统一动作脚本 × 40 人，人均约 200 条序列 ⇒ 同动作平均被约 65 个（人, session）组合拍摄，每 C 有数千帧 B 候选 |
| B/C 姿态逐帧一致 | ❌ 无同步/无跨人对齐 ⇒ 只能"同动作类别 + 姿态检索取最近帧"，属于近似监督 |
| C：A 做新姿态的真值 | ✅ 严格成立的一条路：**A/C 同人同 session 同相机不同帧**——C 是 A 真实做过该姿态的帧，这是精确监督 |
| 严格跨身份逐帧 A/B/C | ❌ 数据集内不构成（需双人同步采集类数据，如 Hi4D） |

结论：FreeMan 把"**有没有 B**"解决了（量大），把"B 和 C 姿态差多少"变成可用检索压缩的连续量；**严格监督靠 A/C，跨身份泛化靠近似 B/C**。

### 2.2 与本项目其他数据集对比

| 数据集 | 域/场景 | 身份规模 | 官方标注 | 分辨率 | 多视角 | 获取 | 对本项目主要角色 |
|---|---|---|---|---|---|---|---|
| **iPER**（已用） | 室内简单背景，单人 | 99 | SMPL（管线内自算条件） | 512 管线已验证 | 单视角 | 公开 | 单人 Body/Face 基线；V6/Qwen21 主训练数据 |
| **Hi4D**（已用） | 室内 mocap 棚，双人接触 | ~百级 pair | 真 SMPL + A/B 掩码 + 接触 | 1080P | 50 机位（取部分） | 已有 | 双人接触分支唯一真实来源（约 822 val / 606 test 对） |
| **TikTok v3**（已建） | 真实舞蹈视频 | 数十 | 仅 DWPose | 720-1080P | 单视角 | 已有 | 真实舞蹈动作多样性；无 SMPL-X（whac 拟合中） |
| **3DPW**（已接） | 真实室外日常，单目多人 | 60+ | 官方 SMPL | 1080P | 单目 | 公开 | 日常场景单目参照 |
| HumanVid 真实部分 | 真实日常（Pexels） | 无身份结构 | 仅 2D 姿态+估计相机 | 1080P | 单目 | 公开可批量 | 背景与光照多样性；无几何真值 |
| PKU-DyMVHumans | 暗光舞台，实拍 | 32 | 无 SMPL-X；多视角+抠像+COLMAP | 1080P/4K，60 机位 | ✅60 | **完全公开**（样本已下） | 备选：真实亚洲人、几何重建基准；非日常场景 |
| DNA-Rendering P1/2 | 棚拍 | 500（亚洲约 40%） | **SMPL-X + mask + 相机** | 4096×3000（12 机位） | ✅60 | 需申请；P1≈192GB | 高清几何主力（获批后） |
| MVHumanNet++ | 棚拍（绿幕/室内） | 4500 身份/9000 套服装 | SMPL-X + mask + 相机（++ 含估计深度/法线） | 采集 4K，**公开图缩半+遮背景** | ✅多 | 需获批 | 扩身份/服装规模（清晰度需实测） |
| SynBody | 合成 | — | — | — | — | **已删除**（融合质量不达标，378GB 已释放） | — |
| **FreeMan（本报告）** | **真实日常 10 场景** | **40（亚裔为主）** | **SMPL + 2D/3D 关键点 + bbox + 相机** | 1080P | **8 机位/session** | 需申请（2~3 天） | **日常场景单人跨身份扩展的主力候选** |

**相对现有数据的核心增量**：
1. **补空白**：iPER/Hi4D 是棚拍简化背景、TikTok 无几何真值、3DPW 单目——FreeMan 是唯一"日常场景 × 多视角 × 官方 SMPL"三者齐备的。
2. **跨身份同动作池**：123 动作 × 40 人天然形成跨身份姿态检索空间，是现有任何数据集都不具备的"近似 B/C"素材库。
3. **8 机位冗余**：同动作同 session 有 8 个视角，可做视角增广与姿态质检交叉验证。

## 3. 数据集不足（以及我们需要做什么处理）

| # | 缺陷 | 影响 | 我们的处理 |
|---|---|---|---|
| 1 | 仅 SMPL[85]，**无 SMPL-X**（手 15×3、脸 jaw/表情全缺） | Hand/Face 分支无法直接用；控制契约是 SMPL-X | 用自家 SMPLest-X/whac 管线升级拟合；官方 SMPL 作初始化与逐帧一致性校验（拟合结果与官方 SMPL 身体关节差应很小，偏差大的帧剔除） |
| 2 | 无 DWPose | 控制契约需要 25 通道 DWPose | 自跑 DWPose（工具现成）；与官方 COCO-17 交叉验证检出率 |
| 3 | 无 mask / depth / normal / parsing | 五类控制条件缺四类 | Sapiens（depth/normal/分割）+ SAM2/parsing 补全；外观绑定所需的 A/B 掩码质量需单独抽检 |
| 4 | 无跨人逐帧对齐 | B/C 只能近似 | 同动作跨人 + **姿态检索**（SMPL 关节旋转距离取最近帧）+ 距离阈值过滤 + 逐对记录误差；误差大的只做预训练，不做精监督 |
| 5 | 人物高度 100~900px 巨幅波动 | 小人物帧对 512/1024 训练无效 | 用官方 bbox2d 先统计分布，按 ≥512px（调试）/≥1024px（高清）建池 |
| 6 | 棋盘格标定板入镜、路人、极端光照（官方自述有背光/过曝） | 污染"日常照片"观感 | 视觉质检过滤（棋盘格检测 + 路人检测），单独标记不进训练池 |
| 7 | 官方标注为半自动管线产物（论文自述用 ControlNet+SAM 做过错误帧检测，但仍有残差） | 控制契约要求严格对齐 | 沿用项目惯例：更新控制缓存版本号、缓存带哈希；抽样复核 SMPL 投影与 2D 关键点一致性 |
| 8 | 无逐帧接触标注（单人数据） | 双人接触分支用不上 | 不碰 Hi4D 职责范围；FreeMan 只负责单人/跨身份线 |
| 9 | 脸部普遍偏小（1080P 全身构图） | **Face 分支不适用**（CG 结论同理：脸信号弱） | Face 训练继续用 iPER/TikTok 现有链路；FreeMan 仅训练 Body/几何跟随 |
| 10 | 获取门槛 + CC BY-NC 4.0 | 不能商用；等 2~3 天审批 | 提交申请；科研用途合规 |
| 11 | `ignore_list.txt`、单目 session 混在全集里 | 脏数据 | 落地第一步按官方清单剔除 |

## 4. 数据集如何使用

### 4.1 获取与落地
1. 提交协议+表单（1.3 节链接），HF 与 OpenXLab 二选一申请。
2. 获批后先下 `subj05.zip`（5.5GB）+ `motions.zip`/`keypoints2d.zip`/`cameras.zip` 验证链路，再批量拉其余 subject。
3. 落地即做三件事：按 `ignore_list.txt` 剔除 → 用官方 `bbox2d` 统计人物高度分布 → 按门槛建 512/1024 两个候选池。

### 4.2 控制条件补全管线（一次性批处理）
```
官方 SMPL[85] + bbox + 相机
  → DWPose(25ch)                      [自跑]
  → SMPLest-X 拟合 SMPL-X（SMPL 初始化）[自跑，输出逐帧与官方 SMPL 的一致性得分]
  → Sapiens depth / normal / parsing   [自跑]
  → 质检：拟合偏差大帧、棋盘格帧、路人帧剔除
  → 按项目契约打包 ConditionBundle（512 等比填充画布、控制缓存版本号+哈希）
```

### 4.3 训练对构建
- **A/C 严格对（主监督）**：同 session、同相机、不同帧。要求：背景/光照一致、人物同服装同体型（同 session 天然满足）、脸部可检出。控制几何 = A 自身 SMPL-X（可加时间扰动构成"同动作不同相位"的跟随任务）。
- **B/C 近似对（跨身份泛化）**：C 取自人物 A 动作 X；B 从其余 39 人动作 X 序列中**姿态检索**（关节旋转距离最小帧），记录 `pose_dist`，按阈值（如关键点 NME 分位数）分级：
  - 低误差对 → 训练监督
  - 高误差对 → 仅预训练/降权
- **体型规则**：控制几何 = `β_A + θ_B`（保留 A 的 betas，取 B 的关节角），重投影处理根位移与落地；**禁止**直接用 B 的 depth/轮廓当控制（会带入 B 体型）。
- **划分**：按被摄者身份隔离（40 人自建 train/val/test；官方 split 为姿态估计任务所设，仅参考）；**B 的身份同样纳入划分**，防身份泄漏；同动作跨人的检索对在划分后重新生成，避免测试身份经 B 侧泄漏。

### 4.4 验收流程（沿用项目规范）
1. 30 组 A/B/C 原图图板逐例人工检查（含 `pose_dist` 数值标注）。
2. 单样本过拟合（512）验证链路可用。
3. 小规模留出身份推理 → 与 iPER/TikTok 基线对比姿态 PCK、背景 MAE、外观相似度。
4. 全程不把 FreeMan 用于 Face 分支（脸太小）。

### 4.5 预期定位（一句话）
FreeMan 承接的是**"日常场景 + 跨身份姿态跟随"的单人 Body 分支扩展**：用严格 A/C 保底精确监督，用大规模近似 B/C 练跨身份泛化，与 iPER（棚拍基线）、Hi4D（双人接触）、TikTok（舞蹈多样性）互补而不重叠。
