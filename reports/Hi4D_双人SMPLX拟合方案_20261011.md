# Hi4D 双人 SMPL-X 拟合方案

## 结论与范围

建议采用 **Hi4D SMPL 网格约束＋全身模型初始化＋多视角双人联合优化**。先将现有身体标注拟合到 SMPL-X，再从 RGB 补充手、脸参数，最后共同优化两个人的接触、遮挡与位置。

本次完成官方方法核对、远端资产核对和候选样本检查。以下为拟合方案，尚未实现新的拟合程序或完成新的 SMPL-X 拟合。

第一轮验证选训练集 `pair14`：源 `talk14/frame32`，目标 `hug14/frame62`。目标帧已有 3753 个标记接触顶点，适合检查交互约束。两帧中的同一人物共享 SMPL-X 体型参数，A/B 固定对应官方人物 ID 0/1。

## 路线比较

| 路线 | 优点 | 局限 | 本项目定位 |
| --- | --- | --- | --- |
| SMPL 网格迁移，再多视角拟合手脸和双人交互 | 利用已有身体标注、绝对位置和接触，适合生成数据标注 | 需要模型对应表、图像约束与联合优化实现 | 推荐作为正式路线 |
| Multi-HMR 直接预测两人 SMPL-X | 一次前向、多人的共同相机空间；资产已具备 | 遮挡、手指及绝对位置需要校正，不能直接当真值 | 初始化与对照 |
| SMPLest-X 按官方人物区域分别预测 | 可提供每个人的全身手脸初始化 | 各人裁剪相机独立，需要恢复到同一标定相机和世界坐标 | 可见手脸初始化或漏检补充 |

官方 [SMPL-X 参数迁移工具](https://github.com/vchoutas/smplx/blob/main/transfer_model/README.md)支持 SMPL 网格拟合为 SMPL-X，并明确要求通过拟合转换参数；两种模型的形状空间、关节位置不同，不能直接复制 betas、pose 或 transl。

[Multi-HMR](https://github.com/naver/multi-hmr) 提供单图多人全身恢复；当前官方 demo 默认已包含 Anny 路线，本项目应显式使用已有的 `multiHMR_896_L` SMPL-X 权重。[SMPLest-X](https://github.com/MotrixLab/SMPLest-X) 可以提供另一种全身参数初始化。

以下多视角、接触和时间约束是针对本项目提出的联合优化方案，需要实现和验证。

## 拟合流程

### 1. 准备相同帧的多视角

第一轮使用：

- 源帧：`pair14/talk14/000032`。
- 目标帧：`pair14/hug14/000062`。
- 同步相机 ID：4、16、28、40、52、64、76、88。
- 各视角 RGB、人物 0/1 实例掩码、相机标定、原始 SMPL。

本次确认两帧的 cam4 RGB 与 SMPL 已存在，其他七个视角尚未提取到 pilot。需从 `pair14.tar.gz` 按需提取同帧 RGB、实例掩码到数据盘的新目录，并逐文件确认归档中存在；不用展开整个归档。

目标 cam4 的 DWPose 中，人物 A/B 都各有一只手的 21 个点全部未达到 0.5 置信度。多视角用于补足可见证据；仍不可见的手部应保存有效性和不确定性，不能伪装成可靠标注。

cam4 的当前标定内参约为：

```text
fx=1118.5837, fy=1118.5311, cx=454.9823, cy=631.9284
原图尺寸 940×1280
```

本次核查 cam4 畸变系数为零，`geometry.npz/K_runtime` 与该内参一致。其他相机单独读取各自标定，不能复用 cam4 的参数。

### 2. 将身体标注拟合到 SMPL-X

使用官方模板对应关系将 Hi4D 的 SMPL posed mesh 转为拟合目标。以有效身体表面的三维误差、边向量误差及共同身体关节误差，优化 SMPL-X 的体型、身体姿态、根朝向和位置。

- A/B 均保留 Hi4D 官方身份索引。
- 使用选定人体资产并记录 gender、资产哈希和模型版本；体型参数通过几何拟合获得。
- 同一人物的体型在源帧、目标帧共享；扩展序列后在整个人物序列共享。
- 身体阶段不依赖不可见的指尖、眼球或口腔对应点。
- 根位置由骨盆或身体表面共同约束，不能将另一模型的 transl 原样使用。

官方 [迁移方法说明](https://github.com/vchoutas/smplx/blob/main/transfer_model/docs/transfer.md)通过模板三角形与重心坐标建立对应，并排除没有对应的区域。

若官方对应表暂时不可用，可先用共同关节、分部位表面距离和实例轮廓做预实验；这条替代方案的身体表面与接触误差需要独立验证，不能直接标为与官方迁移等价。

### 3. 补充手和脸

对每个可见视角提取身体、左右手、脸部关键点及置信度。利用 Multi-HMR 或逐人物 SMPLest-X 作为手姿、下颌和表情初始化，再通过真实相机投影拟合可见关键点。

优先固定或强约束已经拟合好的身体和位置，先优化左右手姿、jaw_pose 和 expression；随后允许有限的身体修正。

仅在多个视角匹配可靠时三角化手脸点。遮挡、低置信度或互相矛盾的点使用掩码与鲁棒误差；完整参数文件中的零值或先验值不等于真实观察。

### 4. 两个人共同优化

建议总目标包含：

```text
身体三维一致性
+ 多视角身体/手/脸关键点重投影
+ 可见人物轮廓一致性
+ 原始接触关系与距离保持
+ 非接触区域穿模惩罚
+ 姿态、手姿、表情先验
+ 连续帧时间约束（扩展到连续帧后启用）
```

相机固定为 Hi4D 标定，不让每个人单独改变相机来掩盖位置误差。人物 A/B 在同一世界坐标系优化。

轮廓损失必须考虑两人遮挡：比较可见表面和实例归属，不能要求被另一人挡住的完整人体轮廓匹配可见掩码。接触处允许接近，非接触处检查穿模。

SMPL 的 6890 顶点接触索引不能直接复制到 SMPL-X 的 10475 顶点。需要用稳定对应关系或限定身体部位的表面对应，重新定义接触区域和关系，并比较迁移前后的接触距离；不能仅按全身最近点任意配对。

## 坐标与参数约定

已有 10 月 3 日接口验证记录可复用，但每次新拟合仍需重建和投影检查：

- Multi-HMR 的 transl 默认关联 head，`transl_pelvis` 是骨盆坐标；标准 SMPL-X 的 transl 为模型加性平移。用同一参数、transl=0 的人体层重建，再根据骨盆位置求加性平移。
- SMPLest-X 与 Multi-HMR 的手部均值约定不同，导出时统一 `use_pca=False`、`flat_hand_mean=True` 并进行完整网格重建验证。
- 预测模型的方形补边、人物裁剪、原图像素坐标、真实相机矩阵必须通过实际仿射变换连接。
- SMPL、SMPL-X、DWPose 的关节布局通过名称或显式映射表关联，不能直接混用数组下标。
- 相机空间到世界空间用 Hi4D 外参转换；旋转、骨盆位置与标准加性平移共同验证，避免重复旋转或重复平移。

## 输出与后续使用

第一轮为源、目标各保存一个双人 SMPL-X 文件，主要字段：

```text
person_ids        [2]
betas             [2,10]
global_orient     [2,3]
body_pose         [2,63]
left_hand_pose    [2,45]
right_hand_pose   [2,45]
jaw_pose          [2,3]
leye_pose         [2,3]
reye_pose         [2,3]
expression        [2,10]
transl            [2,3]
vertices          [2,10475,3]
```

另存相机、坐标单位、人体资产版本、手部均值约定、各部位有效性、关键点置信度、拟合误差和映射后的接触关系。关节数量随人体层选项变化，需要记录关节名称和映射。

这些属于项目生成的 SMPL-X 拟合标注。用于数据制作时可利用对应帧 RGB 拟合；编辑生成时只传入拟合后的几何控制，目标 RGB 仍留在监督和评测侧。

接入 adapter 前重新渲染 SMPL-X 的深度、法线、部位图、人物区域和遮挡图，不能让新 SMPL-X 参数与旧 SMPL 渲染控制混用为同一版本。旧转换器的 6890 顶点蒙皮部位表也需替换为 SMPL-X 对应表。

## 第一轮如何检查

1. 将保存参数重新送入同一 SMPL-X 人体层，核对重建网格、单位和坐标一致。
2. 输出源帧与目标帧的多视角双色网格覆盖图，固定 A/B 颜色，查看是否交换、漂移或穿模。
3. 报告身体三维误差、多视角可见关键点误差、实例轮廓 IoU、接触距离变化和有效手脸点数量。
4. 单独放大四只手及两张脸；区分观察支持的拟合与遮挡下的先验估计。
5. 身体和接触质量相对原始 SMPL 有明显退化时，先调整约束和坐标处理，不扩展到全量。

正式第一轮样本的输出尚未生成，所以本文件不提供一个不存在的项目拟合 CLI。现有预测结果可查看本机 `research/smplx_scan_20261003/multihmr_hi4d_overlay.png`，用于了解初始化，不作为正式标注验收。
