指标各自比较，避免把 Reward 与 raw cosine 混用
Pose 连续 Reward 为 0–1，越大越好；PCK 使用目标有效关节固定分母、漏检记 0，再逐图平均。NME 是按图像对角线归一化的匹配关节误差，越小越好；它只统计匹配到的关节，是诊断项，匹配集合可能变化。ID 只在固定 33 对上比较，另外 17 对不记为零。
ID Reward = (raw cosine + 1) / 2。
RL200 的 glintr100 raw cosine 为 0.6626，对应 ID Reward 0.8313，二者不是同一数值。本报告不把 Pose 与 ID 的 raw 值加成一个总分。

采用 200 步前，先做独立留出集复核
目前 Pose 只覆盖 5 个视频片段，ID 只覆盖其中 4 个；同片段的多对样本彼此相关。200 步是在同一验证集的 7 个 checkpoint 中挑出的，没有使用独立 test 集。样本均值上升可以描述这轮结果，不能作为泛化已证明的结论。
没有“相同额外计算量、继续训练 SFT”的对照，因此既不能证明 RL 方法优于同预算继续 SFT，也不能认定它更省计算。buffalo_l 没有用于训练 Reward，但参与了 checkpoint 的 eligibility guard；它提供另一套特征模型的检查，不是从未参与选择的独立测试。
背景、衣物与手部目前仅有原图和上述 8 张面板的抽样观察，没有全量盲评。不能从 Pose / ID 分数推断这些部分全部改善，也不把 GT 的背景直接当作身份迁移必须复制的目标。
下一步：固定 RL200，与 SFT9520 在未参与选择的新视频留出集上，用相同推理参数做配对评估。
继续报告 Pose、PCK、glintr100 与 buffalo_l，并逐张盲查身份、手部、衣物与背景伪影。只有留出集收益和视觉质量检查都支持采用，才把本轮候选升级为正式结论。
