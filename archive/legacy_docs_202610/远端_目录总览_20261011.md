1. 先看根 `README.md` 与 `docs/PROJECT_STRUCTURE_20261003.md` 了解工作线；
2. 算法实现从 `src/` 进入，运行入口从 `scripts/` 进入；
3. 每个实验的输入、条件缓存、检查点与评测产物见对应 `experiments/*/目录说明.md`；
4. 数据集与权重的组织方式见 `datasets/`、`models/`、`add/` 下逐级说明。
