- **范围**：仓库全部组织目录（代码、脚本、测试、配置、文档、调研、模型、数据集、实验 run、归档、辅助目录）。不含 `.git`、`__pycache__`、`add/` 外部资产区、数据集资产叶子目录（`iper_assets_512_nvdiffrast/<pair>/<模态>/<视角>`）与实验 run 内部阶段目录——这些由所属层 README 统一说明。
- **方法**：分 8 个小组并行，每组对各自子树逐目录 `ls` + 读关键文件（docstring / JSON 顶层键 / 日志尾部）核实后手写；主代理逐份审校（违禁词、内部语言泄漏、自指表述、链接完整性 127 条链接逐一验证）后统一投递。
- **投递**：暂存区打包 tar → scp 直传 → 远端解包；6 个软链目录单独 scp 到链接目标。投递前全量 README 已备份至 `/data/shangguanrz/pic-edit-archive/readme_backup_20261012/readmes_before_20261012.tar.gz`。
