## 4. 系统架构（四层 + 一旁路）

```
输入：源图 + 目标 SMPL-X（25ch 骨架 / 14ch 部件 / 3ch 法线 / 26d 全局 / 11d 相对几何）
  ↓
[静态层 · 每图一次缓存]  SMPLXConditionInjector → ConditionBundle
    → SMPLXAdapterReasoner（单人几何 + 跨人注意力×2 + 接触注意力×1）
    → Geometry / Interaction 独立桥 → PreparedControlConditioning + 身份 tokens
  ↓
[动态层 · 每个去噪步]  SharedRecurrentControlCore
    （几何分支全行执行 / 交互分支仅双人行 gather-scatter；6 stage、rank 64、12 零初始化头、
     共享 1 个从 DeepGen block 0 初始化的全宽 Transformer）
    → ControlStrengthController（geo 1.0 / inter 0.8，恒定/线性/余弦曲线）
  ↓
[注入] 6 组零初始化残差 → DeepGen MMDiT block 0–22（分 6 组 [0-3][4-7][8-11][12-15][16-19][20-22]，第 24 层不注入）
    token 布局：[target-residual | source-zeros | padding-zeros]（参考图 token 补零）
  ↓
[主干层 · 全冻结 BF16] Qwen2.5-VL-3B（≈3.75B）+ Connector（≈0.86B）→ MMDiT ≈2.47B → SD-VAE（8× 下采样）

[旁路 · V6.4 新增] 手/脸 DWPose 关键点 → detail preparer / 区域编码器 / binder（人源+区域+左右手绑定）
    → 绕过 VAE 8× 亚像素瓶颈，detail 残差并入控制核输出
```

**关键设计决策（大白话）**：
1. **零初始化残差 = 安全阀**：适配器输出全部从零卷积起步，关闭时严格等于原生 DeepGen——"先保证不砸基线，再学加分"。
2. **静态/动态分离 = 省算力**：SMPL-X 条件推理每张图只做一次并缓存；去噪 50 步里只跑轻量动态核。
3. **几何/交互双分支隔离**：iPER 只有单人数据，方案 A 把交互分支完全冻结、只在双人行上路由（gather-dual-scatter），避免无监督信号破坏交互先验。
4. **推理不改主干代码**：`controlled_pipeline` 以包装器方式注入控制，DeepGen 上游仓库保持原样。

**组件参数量实测（2026-09-21 权重文件核验）**：

| 组件 | 权重体积 | 参数量（BF16 折算） | 实测依据 |

| Connector | 1.73 GB | ≈0.86B | VLM 特征 → MMDiT context 投影 |

## 6. V6.4 细节分支——昨晚过拟合验证（024_6 单样本，1500 步，24.65 分钟）

**动机**：SD-VAE 8× 下采样使 512 图的手指区域在 latent 中不足一个像素——主干先天"看不清"手指，detail 分支从像素域关键点直接供特征，是对该硬约束的正面解法。

| 验收项 | 结果 | 判定 |
|---|---|---|
| 主干完整性（非 detail 权重 SHA-256） | 一致 | PASS |
| Detail OFF 基线对齐（vs Step 0） | PSNR 51.64 dB | PASS |
| detail 残差 RMS 有限非零 | 0.4979 | PASS |
| Face SSIM/PSNR 提升 | **ΔSSIM +0.2830 · ΔPSNR +2.97 dB** | PASS |
| Hands SSIM 提升 | Δ +0.0721（阈值 +0.03） | PASS |
| 区域外 PSNR 下降 | −0.54 dB（阈值 ≤0.2） | PASS |
| 峰值 VRAM | 15.94 GiB（阈值 <24） | PASS |
| 总 loss 收敛比 | 57.94%（目标 ≤30%） | FAIL |
| Face flow MSE 降幅 | 55.92%（目标 ≥60%） | FAIL |
| 左/右手 flow MSE 降幅 | 50.7% / 51.6%（目标 ≥60%） | FAIL |
| Hands PCK@0.1 | 0.143，Δ+0.083（目标 ≥0.70 且 Δ≥0.10） | FAIL |

**解读**：质量类指标（SSIM/PSNR/区域外保护/显存）全部达标，说明方向有效；未达标项集中在"收敛深度"（loss 与 flow MSE 降幅不足、PCK 绝对值低），指向 1500 步欠训练或单样本容量不足，属可继续推进的问题而非架构否决。

## 10. 风险与建议

| 风险/机会 | 说明 | 建议 |
|---|---|---|
| V6.4 收敛深度不足 | 4 项 FAIL 均为收敛类指标；1500 步可能欠训练 | 提步数至 3000–5000 重跑单样本过拟合，观察 PCK 斜率是否未饱和 |
| HI4D 数据管线版本散乱 | 5 代 build 脚本 + 3 份 .bak 并存，git 未跟踪 | 定稿 v4_2 后收口：删 .bak、git add 收口提交（需先按惯例审计确认） |
| 双人交互尚无正面结果 | 交互分支仍冻结，Hi4D pilot 数据 v4_2 刚构建完 | detail 分支收敛后，以 Hi4D pilot 解冻交互分支做双人 overfit 验证 |
| 全图 PSNR/SSIM 口径盲区 | 白背景主导指标，对小区域手/脸近似失明 | 沿用 V6.4 已建立的区域化指标（Face/Hands SSIM、PCK、区域外保护）作为主口径 |
| 评测口径警告 | OFF 基线因目标姿态通道清零"结构性必败"，对比值被放大 | 报告结论时注明该系统性偏差 |
