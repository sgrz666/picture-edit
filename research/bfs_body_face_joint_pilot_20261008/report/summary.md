# Body + Face + Hand (BFH) 联合调控对比实验总结报告

本报告针对 **Body + Face + Hand (BFH) 三分支联合调控** 实验进行客观总结与多维度对比分析。所有实验均在原生画幅（TikTok 604×1080 零梯度 padding 至 608×1088 步长倍数，推理裁切还原）下完成，且严格使用与此前实验同口径的 TikTok 样本集（训练 256 步锁定 `common256_pairs.jsonl`，评测 24 步锁定 `val24_pairs.jsonl`）。

---

## 1. 实验设置与执行情况

- **硬件环境**：RTX 6000D 80GB GPU，Python 虚拟环境 `/home/shangguanrz/nihaochen/envs/qwen21/bin/python`。
- **基干状态**：Qwen 2.1 DiT 基干权重**完全冻结**，仅对 Adapter 控制器参数进行梯度更新。
- **参数分组与梯度传递**：
  - **Body 分支** (`lr_scale = 0.25`)：调控全身几何特征，保持大身姿态与空间稳定性。
  - **Face 分支** (`lr_scale = 0.50`)：维持人脸高保真 ID 特征与头部朝向。
  - **Hand 分支** (`lr_scale = 1.00`)：激活 Hand Adapter 空间编码器、残差投影与核心控制层，加速手部姿态细节收敛。
- **训练收敛**：
  - 训练步数：256 / 256 步连续无中断完成；
  - 损失变化：总 Loss 从 Step 1 的 **0.6732** 稳步下降至 Step 256 的 **0.2793**；手部 Flow 损失从 **0.7394** 下降至 **0.2191**；
  - 激活步数：Hand Adapter 激活 254 / 256 步，Face Adapter 激活 159 / 256 步；
  - 显存占用：训练峰值显存 42.4 GiB，推理峰值显存 28.5 GiB。
- **评测协议**：
  - 评测集：TikTok 24 个固定验证对（`val24_pairs.jsonl`），30 步扩散推理，24/24 样本成功生成（0 失败）；
  - 手部残差：在 Qwen DiT 全部 6 个 Transformer 阶段均真实注入有效残差（RMS 保持在 0.06 ~ 0.19 之间）；
  - 几何条件：目标 B 身体姿态 + 表面法线 + 面部几何特征 + 手部 DWPose 21 关节点特征。目标 B 图像仅作为离线客观真值，不参与前向计算。

## 4. 核心效果客观评述

### 1) 手部生成质感与动作对齐
- **关节与朝向贴合**：在评测中，24/24 个样本均准确匹配到左右手 DWPose 21 关节点与 ROI 边界框。开启 Hand Adapter 后，手掌正反面朝向、握持手势和伸展手指与目标动作 B 的骨架对齐明显更为精准。
- **结构伪影改善**：在基线分支（如 `BFSBody` 和纯 `Qwen`）中，手部由于缺乏专门的局部几何监督，极易出现“手指融化”、“多指/断指”或“手掌缩成肉团”的伪影；而在 BFH 分支中，手部轮廓清晰，指关节分隔感明确。

### 2) 人脸身份保持度 (ID Similarity) 的显著恢复
- 在此前引入 LoRA 训练的实验中，由于没有精细协调人脸与身体的参数比重，面部 ID 出现大幅下滑（BFSBody 降至 0.4026，BFSHead 甚至跌至 0.3747）。
- 本次 BFH 采用三分支分层调控机制（Body 0.25x / Face 0.50x / Hand 1.00x），成功使面部 ID 回升至 **0.4648**（+0.0901 vs BFSHead），有效维系了源人物 A 的面部辨识度与自然度。

### 3) 全身肢体姿态的稳定性
- BFH 的 PCK 5% 达到 **0.8647**，NME 保持在 **0.0335**，证明在引入局部 Hand Adapter 高学习率训练的同时，并未对全局大身骨架的驱动造成扰动或负迁移。

## 5. 发现的瓶颈与后续改进建议

1. **小分辨率手部潜空间表征限制**：
   - 在 TikTok 原生 608×1088 分辨率下，VAE 经 8 倍下采样后潜空间仅为 76×136。全身人像中手部在整图中占比较小（约 30~50 像素，潜空间仅 2~4 个 Token），极细微的指甲、掌纹细节在全局扩散过程中仍存在表达上限。
   - **改进方向**：可考虑在训练与推理中引入 **Latent RoI Refine** 或局部高分辨率手部 Cross-Attention 增强分支，对手部区域单独做二次潜空间精修。
2. **手部与面部损失的动态调度**：
   - 当前 Hand Adapter 采用固定 lr 1.0x 恒定更新，虽然手部收敛极快，但在训练后半程可能存在对整体底座的细微挤占。
   - **改进方向**：可尝试手部损失随步数进行余弦退火（Cosine Decay），在前期强约束手部几何拓扑，在后期平滑融入大身潜特征。
3. **跨数据集混合泛化验证**：
   - 建议在下一步将 TikTok 竖屏视频帧与 iPER 等正交视角的全身数据集联合打散，进一步验证三分支调控在各种遮挡与光照变化下的泛化鲁棒性。
