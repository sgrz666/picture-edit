# Qwen 双人逐样本动作提示词小规模训练

用户已同意：构建一些带专有动作提示词的训练样本并训练，最后用一条测试集样本测试；测试不能反向传播。

## 范围与输入

继续使用 dual_v8、512 方形等比填充、一张双人源图、A/B 源掩码与独立外部目标几何。原始 Hi4D SMPL 通过已有拟合工具生成真实 SMPL-X 拓扑，源目标共享各自人物 beta。目标 RGB/真值掩码仅用于训练监督或生成后评分，文本仅依据源人物指认、动作标签和可靠外部几何。手指遮挡先验不编写成确定动作。

按现存 split.json 选择四条训练配对，覆盖两个训练 pair 与两类交互；另取一条现存验证划分配对选择检查点，一条现存测试划分配对作为最终测试。pair 互斥；数据没有跨 pair 全局演员 ID，不能额外宣称已核验全局演员身份互斥。文件 SHA、原始清单行、帧/相机和 prompt 原文全部记录。测试清单只用于冻结检查点后的生成与评测；构建测试控制允许使用该任务约定的外部目标几何，不能更新生成模型。

已核验选择：训练 pair14 talk14/32→hug14/45、hug14/62，pair12 highfive12/28→highfive12/33、highfive12/82；验证 pair22 game22/52→hug22/46；测试 pair00 taichi00/41→hug00/108。均为 camera4，原始资产全部存在，无需解包。前后两条 highfive 分别处于低位手部接触和高位击掌阶段，提示词阶段必须由可靠目标几何确定。

旧 pair14 拟合是 source/target 联合估计共享 beta，不能作为本轮 source-only beta 证据。所有配对重新拟合：只用源帧的原 SMPL 身体关节/表面估计源 beta，然后固定 beta 拟合目标姿态/平移。源 DWPose 对本轮几何拟合不是必需输入；未观测手脸使用明确标注的先验。

## 文本与对照

短提示词和结构化提示词使用相同动作标签。结构化文本按统一模板填入源人物 A/B 指认、动作、可靠朝向/接触和保留要求。人物的源图左右关系仅用于指认，不能按目标左右重新分配身份。每个可靠几何描述绑定输入特征与阈值；未知细节省略，不使用目标 RGB 生成描述。

两套 adapter 从同一 iPER step19500 检查点及相同随机初始化独立开始，各训练 300 optimizer steps，有效 batch4、lr1e-4、相同样本顺序/噪声种子/损失。Qwen 与已导入单人几何部分冻结。原先 300 步单帧双人检查点不作为初始化。每50步在验证样本上用固定噪声且关闭梯度计算 flow loss，只用验证结果选 best。

## 测试与证据

最终测试在 best 已选择并写入训练完成记录后进行，原生短/结构化文本与各自训练的 adapter 各生成一组；种子42/43/44、40步、CFG1、同源图和外部几何。原生不接收密集几何控制，但结构化文字含外部几何提取的动作描述；图板分别标注文字几何描述与显式 adapter 控制。所有生成进入 inference_mode；禁止 Tensor.backward、autograd.backward/grad、optimizer.step，并记录 guard 次数、梯度开关、参数 grad、adapter/主干生成前后 SHA。

保存训练样本/提示词清单、loss 曲线、测试逐例 PNG 和图板、可计算的 A/B 姿态与接触代理、身份/背景指标及失败覆盖。不能把漏检当成功，不能根据这一个测试配对推断总体泛化或声称已达到双人质量门槛。本轮交付需要实际运行训练与测试，不以代码或空清单替代。
