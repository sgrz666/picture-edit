# Full 方案 C：编码、Qwen 主干适配与 Depth

## 研究目的

按用户 2026-10-22 的选择，以现有 Full 为基准，研究直接接入 Qwen 主干的轻量人物几何控制。后续由当前智能体独立执行，不派 subagent；不再迁入或加载 Union 控制权重。

## 关键结论与使用

保留 Full 的 Body25/Normal/Part 编码、256→512 几何推理和高低分辨率融合能力；用读取 Qwen 当前目标 hidden 的 4096→512→4096 模块替换 Body 的旧 SD3 控制核。首轮分离接口迁移与 Depth 增益，避免把层数、输入、损失同时改变。一个共享 down projection 和六个 up projection 仅权重有 14,680,064 个元素，不代表整个 Adapter 大小。

当前深度读取既有灰度可视化图，也有经过 min-max 的数组路径；没有证据证明它们全部是相同方向的米制 Z。先统一来源/有效性/相机，再比较 depth+valid、梯度边界和局部部位排序。不要直接把 `use_depth=True` 当成旧 checkpoint 无损升级，它会把旧 fusion 的输入从384改成512通道。

使用时先读报告第2节的来稿判断，再读第4–7节的候选接口和对照。第8节列了未来实施验收；这些是待执行项，本次没有运行模型测试。研究只新增本文档与证据，服务器保持只读。
