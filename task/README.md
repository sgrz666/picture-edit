# task/ —— 合同任务书（权威验收来源）

项目与合同方签定的**人物图像姿态编辑任务书**存放目录，当前只有一份文件：`人物图像姿态编辑任务书_v3.docx`（44,981 字节，2026-10-14 09:49 落盘）。它是本仓库**验收条款的权威来源**——所有主观验收口径、六轴补测指标、目录约定都最终回溯到这里，引用验收条款时一律以 v3 为准。

## 里面有什么

- `人物图像姿态编辑任务书_v3.docx` —— 合同任务书正文（Word，二进制）。内部结构（按文档段落还原）：
  - **合作需求/任务**：总纲，明确"保持身份、服饰、场景一致的前提下实现身高体型解耦与参考姿态图像编辑"。
  - **1.1 研究领域**：基于三维人体表示的人物图像姿态编辑算法。
  - **1.2 研究目标（三个）**：① 控制信号表示方案（参数化模型/法向图/接触图等）；② 单人与双人交互姿态重定向，支持拥抱、搂肩等接触交互与手指级精度；③ 显式/隐式控制信号注入生成模型的编辑方案。
  - **1.3 交付成果**：软件交付（身高体型解耦的单双人精细交互重定向代码、高真实感编辑算法原型代码、单双人参考姿态编辑算法原型代码）；文档交付（3 份研究报告 + 原型与评测说明文档）。
  - **项目阶段**：阶段一 T–T+6（基础方案、数据集、初步实验、基础评测流程），阶段二 T+6–T+12（整体算法流程、复杂交互、工程整理、最终交付）。各阶段含任务描述、目标、交付成果、**验收标准**与**验收方法**。
  - **验收标准（合同关键，凭此验收）**：阶段一"身高高低/体型胖瘦相对估计准确率 ≥ 60%"、"典型双人交互姿态生成主观合理比例 ≥ 70%"；阶段二分别提高到 ≥ 80% 与 ≥ 90%，且"图像编辑主观质量优胜率相比 Qwen-Edit 基线高于 5%"。
  - **项目监控和管理**：月报、双周会议等机制。

历史上若有其他版本任务书，当前目录不含——以本 v3 为现存唯一版本。

## 与项目的关系

- **主观验收对照**：`workflow/human_eval/` 的三条主观验收（合理比例、优胜率、Fleiss κ 等）口径来自任务书阶段二验收标准；合同里那条"身高高低/体型胖瘦相对估计准确率"目前仍无机器指标覆盖。
- **定量评测对照**：`workflow/evaluate2.py` 的六轴无 GT 补测（DWPose 一致率、骨长比漂移、ArcFace 身份余弦等）是为补任务书未覆盖的方向而做，但任务书直接点名的上述几条仍未被任何指标覆盖。
- **目录约定来源**：`AGENTS.md` 里关于目录职责与"保护资产/受保护"的约定，源头也追溯到这份任务书与各阶段交付清单。
