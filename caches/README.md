# caches/ —— 运行期条件缓存

运行期条件/控制特征缓存目录。当前主要通过符号链接外挂大型缓存，实体不在本仓库内。

## 里面有什么

- `qwen21_hi4d_controls/`：符号链接 → `/data/shangguanrz/pic-edit-caches/qwen21_hi4d_controls`。存放 Hi4D 双人控制特征缓存（`.pt` 文件，每个约 47 MB），由 Qwen-2.1 Hi4D 控制特征计算产出，供重复实验直接复用、避免重算。

## 与上下层的关系

- 被 Qwen-2.1 相关的推理/评测读取（Hi4D 双人控制）；实体随挂载位置变化，链接目标在仓库外。
- 相关：`add/README.md`（外部资产区）、`logs/README.md`。

## 注意与坑

- 链接目标在 `/data` 挂载盘，**不在 Git 内**；移动挂载点或清理 `/data` 缓存会使链接失效，需重新生成缓存。
- 链接本身轻量，请勿把它当作"已备份"的缓存本体。
