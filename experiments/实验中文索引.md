## 为什么没有直接改目录名

本次只加索引、未动目录名，是基于以下实测结论（2026-10-13 审计）：

1. **项目自己的规则**：总 README「四、规范与注意事项」第 1 条明确——已完成并记录 `summary.json` 的实验目录**严禁改名**，以保证证据链完整可信。
2. **功能性引用 42 个文件**：训练/评测/运行脚本里有硬编码路径，例如 `src/pose_control/qwen21_full/execution.py` 写死 `experiments/iper_v6_native_20k_v1/checkpoint_last.pt`；`scripts/train/` 多个入口的默认输入输出就在这些目录；`configs/asset_registry.json` 登记了冷 run 路径。
3. **冻结证据 29 个文件**：15 个 workflow 运行的 `run.json` / `stage.json` 把输入路径写死指向 `experiments/qwen-2.1-test/data/testset/pairs/...`，改名会使这些记录的复验（`--verify`）失败。
4. **运行中的主研究**：8-arm PE-I2I 研究（10-11 起跑，仍在 rewrite 阶段）的 3 个脚本引用 `experiments/tiktok_objective_eval`、`tiktok_v65_face_overfit_00001`、`tiktok_v65_pure_inference`。
5. run 内部的 `run_manifest.json` / `summary.json` 还记录了旧绝对路径。

若确认要中文化目录名，可执行「改名 + 全量引用更新 + 旧名留兼容软链」方案（兼容软链保证冻结记录与脚本不断），本表即可作为改名映射直接使用。
