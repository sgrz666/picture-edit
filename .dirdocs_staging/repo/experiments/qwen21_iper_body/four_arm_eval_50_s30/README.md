> 路径：`…/qwen21_iper_body/four_arm_eval_50_s30`　|　3 文件 + `strips/`（50 拼图）/ 53 文件 / 42.6 MB　|　数据源：`summary.json`，2026-10-12

## 一、在干什么
四臂协议（deepgen_off/on、qwen21_off/on，seed 42、50 held-out 对）把采样步数从 40 降到 **30 步**，验证结论对推理预算的敏感度。

## 二、内容实证（30 步均值）
| 指标 | deepgen_off | deepgen_on | qwen21_off | qwen21_on |
| :--- | :---: | :---: | :---: | :---: |
| PSNR | 17.35 | 24.54 | 17.55 | **25.91** |
| PCK@0.02 | 0.174 | 0.955 | 0.206 | **0.979** |
| Face ID | 0.258 | 0.297 | 0.822 | 0.353 |
| 耗时 | 3.87s | 4.51s | 4.46s | 4.49s |

30 步下 qwen21_on PSNR 反而 25.91（vs 40 步 25.86），PCK 98% 几乎不变，单图耗时省约 1.4s——**降低采样预算不损失结论**，但对外权威仍用 s40。
