# 小红书训练优先与多 seed 出图

用户要求加快训练并多生成图片。实测无加权 S0 已训练，GPU utilization 91%，当前主要可省的墙钟开销是每阶段后阻塞式完整验证出图／评价（首轮 40 图约 20 分钟），不更改已运行的优化器、精度、学习率、数据、预算或训练核心源码。

- [ ] 新编排器接管当前 S0 子进程，精确绑定 PID／启动标识；只替换等候它的旧主管，当前 SGD 进程保留，严禁重复启动训练。使用同一冻结训练 src 和已通过的真实梯度报告。
- [ ] SFT／后续 SFT／GRPO 的完整评估图片后置；每阶段保存并锁定真实 checkpoint 和 generation config，训练先连续完成，测试仍全部优化结束后评价。
- [ ] 最终五份权重各输出 64 对 test×3 seeds（42／123／2026），共 960 test 图片；final 模型 val 增加 seed123，阶段 val 保留 seed42，合计 640 val 图片。总计 1600 张，原 40 张 baseline 不覆盖。
- [ ] 每份 checkpoint 只加载一次 Qwen，用一个进程连续生成该模型的所有 split／seed。SDPose 和身份／背景评价批量执行，再按模型／split／seed分组；seed42 保持原主对照路径与口径，其他 seed 单独归档，所有实际模型 SHA 校验。
- [ ] CPU 回归覆盖任务计数、配对种子、旧图片复用和接管条件；编译／SHA 验收后投递，记录当前更新数、主管和训练 PID，更新实验 README 的查看与复测命令。
