# 手部区域漏加权修复

根因：v1 将 MediaPipe 精细手部可训练开关当作整个可见手部区域的门控，1960 张只有 140 张增强。用户要求修复并小样本验证，不重跑全量、不修改原 loss_mask。

- [x] 先添加失败回归：MediaPipe 缺失但 DWPose 可信时产生粗区域；低置信、出画、明确遮挡、错误 wrist 关联和背景点不增强；小手 area pooling 后仍有增量。
- [x] 增加显式 visible_region_v2 策略，保留 legacy_strict。DWPose 粗区域与 MediaPipe 精细区域分别校验，max 融合，粗区域较低权重；逐手记录来源和拒绝原因。训练 Loss 公式及系数保持不变。
- [x] 增加原 Body Mask 缓存复用，不加载 SAM。新变体保留 donor index／PNG SHA，旧数组和标记不变。同步审计器，按实际策略核对区域，不把绕过精细门控错误判成绕过可见性。
- [x] 用上一版 20 张和额外遮挡／出画负例做新旧对照，至少包含 BV14NHK6SE9d_000286；记录像素与 latent 的每只手权重增量，不靠颜色判断。人工查看修复例及负例，运行相关回归，更新中文 README 和测试使用命令。
