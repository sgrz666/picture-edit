# BFS Body + Global Adapter 主线实验计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有数据、几何输入、Global 结构和训练预算下，验证固定 BFS Body 是否能成为更好的 Adapter 适配底座。

**Architecture:** 使用现有 `Qwen21FullAdapter` 的 Body/geometry 路径；Qwen、BFS 均冻结，只训练当前 Body 优化器覆盖的参数。原 Qwen 与 Qwen+BFS 两组从同一个已继承的 Adapter 初始化出发，分别适配相同的 TikTok 数据；首轮关闭 Face、Hand、Interaction、Detail 控制。

**Tech Stack:** sg 上已有 PyTorch 2.8.0、Diffusers 0.41.0.dev0、PEFT、Qwen-Image-2.1、TikTok letterbox 数据链路与 Full Adapter 训练/评测入口。

**状态：** 2026-10-08 完成实验设计及已有资产核对。没有接入新的训练代码，没有启动 BFS 训练。GPU 上正在进行的 native-value 推理审查由其原有任务管理。

## 2. 固定主协议

生成条件仅为 **源 A RGB + 目标 B 几何**，输出保留 A 的身份、衣服与既定背景，服从 B 的目标姿态。B RGB 只用于监督 latent 和离线评测/展示，不能作为生成参考图或目标身份 embedding 输入。

本轮沿用现有 normal/part/mask/SMPL-X 条件与相机、letterbox 处理。暂不改变 shape 来源、重渲染几何、生成标准站姿 A、输入顺序、参考图数量、损失或控制分组，否则无法归因于 BFS。

BFS 的官方原生“两张 RGB”工作流与这条协议有差别。因此本轮回答的是 **BFS 先验能否改善现有几何控制任务**；负结果只限定于本轮输入/训练协议，不能推广为 BFS 原生换人能力无效。

BFS 原生 body_swap 提示词引用两张图，本轮只有一张 RGB，不直接照搬。两组使用旧训练的同一个提示词，不分别为某一组优化提示词。

## 3. 最小而完整的分组

将原底座训练出的 Adapter 记为 G0，将固定 BFS 底座训练出的 Adapter 记为 G1。

| 组 | 推理底座 | Adapter | 角色 |
| --- | --- | --- | --- |
| A | Qwen | G0，对应阶段检查点 | 主基线 |
| B | Qwen + 固定 BFS Body | G1，对应阶段检查点 | 主候选 |
| H | Qwen + 固定 BFS Body | G0 | 热加载诊断：只加载是否有益 |
| X | Qwen | G1 | 适配依赖诊断：关闭 BFS 后的变化 |

正式比较是同一步数 **B − A**。H 与 A 区分热加载收益；B 与同预算 H 区分任务底座适配的价值。X 是分布切换诊断，不能冒充候选正常配置。

额外用少量样本对照 Global 关闭的纯 Qwen、Qwen+BFS，确认 LoRA 开关有作用；无几何控制的生成不用于宣称目标姿态控制成功。

首轮 BFS strength 固定 1.0，登记有效模块缩放和权重哈希。0.5 强度作为后续独立敏感性实验；若首轮 1.0 有退化，不得暗中换 0.5 后沿用同一结果标签。

### P1：1,000 步候选试训

- [ ] B 组从共同初始化训练 seed42 permutation 的前 1,000 对，保留 0/1000 检查点。

### P2：继续一遍训练

- [ ] 有限值、梯度与接口正常时，继续到 3000、6000、8548，保留优化器和随机状态，不重置 warmup。
- [ ] 每个节点都对相同 36 对做 A/B 同步比较，绘制质量随已见训练 pair 数变化的曲线。
- [ ] H 固定在 G0 的 6000 步节点做 36 对诊断；X 用最终 G1 做 36 对诊断。

- 跨人物 20 对：使用明确不同 iPER actor 的 A/B 和既有几何条件，以 1708 固定选样，覆盖多个 A/B；源参考资格、几何有效性在生成前检查。

共 146 对，在最终 8548 步 A/B 两组以采样 seed `[42,123,2026]` 生成，共 876 张。本轮采用两个组共同的固定采样设置；尚未存在的扩大清单由执行阶段构建并记录哈希，不把它写成已完成资产。

跨人物没有对应真实 C 时，不计算输出对 B RGB 的 LPIPS/PSNR 作为身份外观质量；B 只用于姿态评测，身份和衣服比较源 A。目标几何仍保持现有定义，记录可能包含 B 体型信息的限制。

TikTok 的 96 对仍来自同样 3 个视频组；增加帧数不等于增加独立人物。当前没有 certified 人物互斥，不能宣称未见人物泛化。iPER actor 可以聚类，但共同初始化可能已有 iPER 训练暴露，需记录其范围。

原有封存最终 test 保持封存；只有所有配置和选择规则完成锁定后的最终验收才使用，不能拿来选择 strength/prompt/checkpoint。采样三个 seed 衡量生成随机性；它们不等于三个独立训练 seed。进一步宣称训练稳定性需要额外的配对训练重复。

## 7. 指标、统计与结果判定

### 统一评分

- 身体：PCK@0.02/PCK@0.05、连续 NME、可匹配关节覆盖率；身体点与头部点分开报告，正确处理实际尺寸与 letterbox 有效区。
- 身份：对 A 的 ArcFace cosine，加源参考资格率、输出无脸/多脸率；分侧脸、遮挡、大小脸检查，避免仅偏好复制 A 的朝向。
- 外观：源 A 服装区域的 DINO/局部外观指标和完整人工对照；姿态导致的衣物投影变化不能直接当像素错误。
- 背景：沿用源 A 背景的 MAE，但从评价区排除源/目标人体编辑并集和 padding；统一 [0,255] 尺度。
- 头部/表情：沿用已有二维头部辅助审查，明确其不是完整三维头姿。Global 首轮对细表情仅作探索性检查，最终 Face 阶段再验证可靠 B expression/jaw 控制。
- 工程：训练耗时、采样时延、显存、非有限值与冻结/梯度状态。

源脸资格在生成前固定。身份 cosine 仅对 A/B 都有可评分输出的配对集合报告条件均值，同时报告所有输入的输出失败率、单组有效数和未配对原因。不能只报共同检测成功样本而隐藏输出失败，也不跨所有训练节点取人脸交集将样本缩小到少数成功例。

TikTok 与 iPER 单列，按视频组/已知 actor 等权报告配对差值；重复帧和不同采样 seed 不当作独立人物。TikTok 只有 3 个验证视频组，区间只能作探索性描述。已有实验共检集合里 iPER 仅 2 对的身份均值不能作为本轮身份结论。

### 预先声明的工程候选标准

主目标为在保持几何能力的同时改善源身份/外观。首轮候选条件：A 身份配对 cosine 平均增益至少 0.02，PCK@0.02 降幅不超过 0.02，区域外背景 MAE 按 [0,255] 计算的增幅不超过 1（归一化后不超过 1/255），且无新增成片严重失败。

这些数值是暂定工程门槛，不是经过统计估计的通用显著性阈值。预先报告配对区间、覆盖率、逐组差值和全部图，不能把超过均值门槛直接称为统计显著。

若主要收益是姿态，身份略降，应作为另一种取舍单列，并由扩大集验证；不自动归入“身份保持改善”。初轮通过只进入候选阶段，不自动替换正式基模。
