# HIA 脸手清晰数据集 V1

2026-10-26，用户已批准继续按前一轮方案构建。数据源仅使用 sg 已落盘的 HIA-RAW；不需要重新下载或访问上游受限页面。

## 目的与当前证据

从 25 个 RGB ZIP 中的 25,000 个视频选取真实清晰的单人动作帧，输出独立 train/val/test 和同人动作编辑 pairs。原始 ZIP、视频、图片和 CHAMP 产物均不改写、不删移。

磁盘审计：源 manifest 记录 51 文件、109,953,223,390 bytes、problems=[]；25,000 个 RGB/pose 文件名对应，但 pose 是渲染 MP4，不是数值关键点。012831 的 RGB/pose 是 300/301 帧，不能按 pose 帧数推导 RGB。CHAMP 的 10 条源视频也在 HIA，已对 000000/000555 校验视频 SHA256 一致。

CHAMP 的人体 Laplacian 门在既有模型视觉标签样本中仅检出 14/38 个模糊帧。沿用其无损抽帧、wholebody 数值关键点和动作配对思路，重新建立面部与每侧手部的局部门；不把旧 pristine 标签视作真值。

## 处理方案

独立实验代码位于 experiments/hia_face_hand_dataset_20261026，运行产物落 /data/shangguanrz/pic-edit-datasets/HIA_face_hand_v1_20261026。服务器上的实验说明和代码位于 experiments/6.qwen-controlnet union/hia_face_hand_dataset_20261026。代码由 scp 直传后 py_compile；不更改现有训练、依赖和模型。

1. 全库 ZIP 中央目录清点，写可追溯来源清单。候选抽样覆盖全部 25 个分卷，固定 seed，逐步扩大到足够的合格视频，记录实际覆盖规模，不把未处理视频称作筛选完成。
2. 每段视频按 2–4 FPS 抽候选，按 RGB 索引/PTS 定位。先在少量分层视频上计时与检查；解码视频在内存文件中打开，避免重复解压 100 GiB 和遗留临时媒体。PNG 仅保存入选候选与明确复核样本。
3. 用现有 CPU ONNX DWPose 检测单人和 wholebody134；布局 body18+foot6+face68+hand21+hand21。先核对可见性/几何/原生像素预算，再算局部 Laplacian、Sobel、多尺度梯度和亮暗饱和指标。脸、两手分别保存结果；低置信度、遮挡、出画、太小和模糊使用不同拒绝原因。
4. 严格主集要求脸与两手全部通过。按邻域质量择优后，再做身体姿态去重；不要求每段视频必须有产物，不靠锐化/超分/生成修复补细节。固定阈值须留档并通过原生 ROI 视觉检查，不使用每视频前若干百分比强制放行。
5. 用户最终确认完整视频隔离：同人物的不同视频可跨集合，用于新动作评估。同视频、同 SHA256、确认感知近重复不跨 split。参考帧与目标帧只在同一视频/估计镜头中配对。以80/10/10为视频组目标。CHAMP 的000000/111/222/333/444/666/888继承train，000555继承val，000777/999继承test。
6. 现有ArcFace生成的人脸近邻审计保存为诊断，不作为视频协议的强制并组依据。summary明确same_person_may_cross_splits=True及cross_identity_independence_verified=False。动作距离采用固定工程门，无val/test拟合。
7. 产出 PNG、数值关键点、局部质量记录、来源及 SHA256、划分清单、同人动作 pairs 和复核图册。该版本交付 RGB/2D pose 数据；是否有 SMPL-X/深度/法线必须明确标记，不把不存在的几何条件写作可训练资产。

## 验证与使用

自动检查所有导出图片可解码、原尺寸不拉伸、SHA256与来源帧对应、关键点范围、三部位通过、split间视频/哈希零交集、pair两端均在同一split及同镜头、CHAMP冻结归属不冲突。抽取独立视频检查通过和拒绝样本的原生脸手图册，发现高分但模糊的漏网帧则收紧门限并生成新版本清单，既有图片不覆盖。

README 写实际视频/帧/pair数、拒绝原因、运行命令、局部门阈值、视觉复核覆盖及限制。提供 verify 命令与最小读取示例。整个构建不改现有训练进程，不自动启动训练。

## 执行中确认的口径

首版以每卷100段、共2500段分层视频为主；合并性能试跑后实际覆盖2880个不同视频。粗筛采用1 FPS、每视频最多8帧；23个通过局部复核的来源采用4 FPS、最多40帧加密，避免把整库25,000段都声称为已精筛。三个池去重后307张自动候选逐帧做Codex视觉复核，98通过、164拒绝、45存疑。该复核记录human_confirmed=false。

DWPose的SimCC响应为原始响应值，可能超过1；不作概率范围裁剪。24张脸与双手已通过视觉复核的图像，其越界点全部在body/foot、且只越下边界；共body32点、foot70点，脸与双手110个可信点全部在图内。正式标注保留candidate与raw confidence，增加keypoint_valid_mask、confidence_for_training和bounds_and_raw_response_v1口径：仅raw>=0.3且落在原图内的点参与监督和动作距离。可信脸/手越界仍拒绝。原始pose JSON保留，带有效点掩码的新JSON写到正式版本目录。

配对除body变化外允许手指或表情变化独立准入，固定门为body>=0.06、任侧hand>=0.10或face>=0.06；时间间隔默认0.3秒。人物隔离尝试曾使用保守人脸近邻连通组，未能形成三个可配对组；用户最终选择的视频协议按完整视频、SHA重复及近重复归组，保留CHAMP源视频冻结。正式发布保证train/val/test每个split都有可用动作对；只允许调剂无冻结约束的完整组，并保存调剂审计。

所有JSON元数据先写唯一staging文件、flush/fsync后用os.link原子发布；staging保留，无删移媒体。正式目录只有在结构与全帧源像素回验均通过后才能创建READY.json。

最终发布采用用户确认的视频协议：video_split_v1包含96帧、31个源视频、30个视频组、81对；train/val/test为70/12/14帧、57/2/22对。视频组分配24/3/3。正式全部96帧做源像素回验及全量导出后近重复检查，12对候选经过低分辨率像素MAE/NCC确认，跨集合确认近重复为0。人物隔离尝试因只有2个独立paired组未发布，作为诊断证据保留，正式视频协议允许同人物跨集合。
