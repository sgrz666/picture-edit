# MultiHMR 双人联合精修设计：可见点监督与有符号穿透约束

日期：2026-11-03
状态：设计已获用户对话确认，待书面审阅与实施计划

## 1. 目标与边界

先在 Hi4D 的 127 张冻结双人帧上验证一个单图双人精修器：以 MultiHMR 672 的双人 SMPL-X 为初值，用 Sapiens2 的独立二维关键点校正可见姿态，再在共享相机坐标中联合优化两人，减少真实人—人穿透，同时不退化可见点投影和双人相对位置。

首版拟合只允许使用 RGB、真实相机内参和模型预测。`request.json` 中的 GT 框、GT 关节、实例掩码、原始 SMPL 和接触标注只能进入独立评测代码，不能进入候选选择、损失、迭代接受或超参数在线调整。超参数只在原有 train 记录上拟合，在 val 上选择，test 冻结后只跑一次最终对照。

首版不做多视角、时间平滑、模型重训、详细脸手重建，也不把 MultiHMR2/Anny 或 SMPLest-X 的逐人裁剪三维直接混入共享场景损失。普通双人 RGB 的迁移是后续工作，不把 Hi4D 结果宣称为通用能力。

## 2. 当前磁盘证据与问题分解

只读核查得到以下事实：

- 输入为 `/data/shangguanrz/models/two-man/benchmark_results/M2_MultiHMR_672/predictions.pkl`，包含 127 帧、每人 10475 个 SMPL-X 顶点、127 个关节、`rotvec[53,3]`、`shape[10]` 和共享相机空间中的 `transl_pelvis`。
- 原始检测中恰好两人 60/127，超过两人 65/127，少于两人 2/127，至少两名候选 125/127。超过两人的情况不能未经归并就称为多个真实人物。
- 样本 `243780fa6b6994fc` 有四个候选，其中两对的骨盆位置和身体参数非常接近，渲染上的四层人体首先是重复实例问题。去重之后仍需另行测量两名真实人物之间的穿透，二者不能混为一个指标。
- MultiHMR 当前推理只返回逐人网格，没有人—人碰撞损失。仓库现有 `bounded_contact_shift` 也明确写着 `penetration_status=not_measured_no_FCL`，现有顶点对应距离不能冒充穿透量。
- 单人 Sapiens2 修复线可复用的是方法而不是直接复用单人损失：可见性分类、低置信或遮挡部位冻结、受控 Adam 精修、初值正则和逐帧记录。其单人管线本身不包含双人碰撞项。
- Sapiens2-DETR 缓存已存在于 `/data/shangguanrz/models/two-man/benchmark_results/M3_Sapiens2_detr/`。首版 pilot 直接读取缓存，避免重复运行 5B 模型。
- `/data/shangguanrz/models/two-man/M4_MultiHMR2/env/bin/python` 已具备 `torch`、`smplx` 和 `warp`。Warp 用于带符号最近表面查询；不向 `qwen21` 环境安装任何包。

因此首版必须依次解决三个不同问题：候选重复与漏人、可见姿态误差、两名真实人物的三维穿透。只加碰撞排斥而不处理前两项，会把副本当作额外人体，并可能把正常拥抱强行推开。

## 3. 路线选择

### 3.1 轻量去重与平移修复

自动选取两名不同候选，仅通过平移消除重叠。它适合作为对照臂，不足以修复手臂、肩颈和躯干姿态，也可能破坏接触关系。

### 3.2 分阶段多模型联合精修（采用）

MultiHMR 提供共享相机中的双人 SMPL-X 初值；Sapiens2 提供独立二维观测；可见性门控决定哪些部位可动；有符号点到网格距离提供真实穿透监督；逐帧接受规则保证没有把观测指标换坏。

### 3.3 重型多视角或交互模型重建

同步多视角、PromptHMR/BUDDI 一类路线可能提高上限，但首版依赖、坐标和验证成本过高。现有 PromptHMR 后处理代码只含重投影、地面、时间和平滑/接触项，没有可直接采用的人—人穿透损失，因此不作为首版捷径。

## 4. 实验与模块结构

新实验归入现有 `mete-test` 族：

```text
experiments/mete-test/dual_mesh_refine_20261103_v1/
├── README.md
├── data/                 # 输入引用、冻结配置与哈希，不复制 42 MB 原始 pkl
├── scripts/              # 候选选择、精修、穿透评测、汇总
├── tests/                # 映射、碰撞量尺、接受规则、覆盖率回归
└── report/               # 小型文字报告与面板索引
```

大产物写 `/data/shangguanrz/pic-edit-experiments/mete-test/dual_mesh_refine_20261103_v1/`，不改写原始 `predictions.pkl`、Sapiens2 缓存和旧 benchmark 汇总。每帧输出独立目录，包含所选两人参数、重建网格、逐次指标、状态、输入哈希和配置哈希；已存在产物默认拒绝覆盖。

模块边界如下：

1. **Observation reader**：只读取 RGB、相机、MultiHMR 原始候选和 Sapiens2 缓存，按具名 body-12 契约导出观测。GT 字段由另一个 evaluator 读取，拟合 worker 不接收这些字段。
2. **Candidate selector**：完成重复实例归并、两名人物选择和与 Sapiens2 实例的对应。
3. **Visibility gate**：逐人逐关节决定二维观测是否可用，并生成需要冻结的身体部位。
4. **Joint refiner**：在固定真实相机下优化两人的 body pose、root 和 translation；betas、脸和缺乏可靠观测的手姿首版冻结。
5. **Collision backend**：双向查询顶点到另一人网格的最近面、符号和重心坐标，提供量尺与 Torch 穿透项。
6. **Acceptance and export**：保存所有迭代诊断，只导出满足非退化约束的最佳迭代；没有合格迭代时保留所选初值并写明原因。
7. **Independent evaluator**：单独读取 GT，计算二维、三维、相对位置和分场景指标，不能反向调用拟合器。

## 5. 候选选择与人物归属

MultiHMR 的 body-12 使用显式 SMPL-X 索引 `[16,17,18,19,20,21,1,2,4,5,7,8]`，Sapiens2 读取已有 `joint_names`，禁止按数组位置猜测关节。

候选与 Sapiens2 实例之间使用可见身体点的鲁棒投影距离做二分匹配，距离按对应人物框对角线归一。候选对还要计算投影框重叠、骨盆深度/三维距离和 root-relative 姿态相似度，用于识别同一人的近似副本。选择顺序为：

1. 优先得到两个不同候选与两个 Sapiens2 实例的一致匹配。
2. Sapiens2 缺人时，只允许在 MultiHMR 候选中选择非重复且检测分数可靠的一对，并降低该帧观测覆盖标记。
3. 可靠不同候选不足两人时输出 `insufficient_observation`，不得复制候选凑成两人。
4. 人为交换两人的 Sapiens2 观测必须被高匹配代价或归属门拒绝，作为反向测试。

GT 只在评测中判断自动选择与 oracle 选择的差异。所有 127 帧都必须有状态记录；有效拟合覆盖率与候选选择准确率分开报告。

## 6. 可见性与联合优化

二维观测采用 Sapiens2 置信度、人物归属间隔、画面裁切和另一人遮挡联合门控。初始置信门槛沿用单人线的 0.3，后续只能在 train 上调整。以下观测不进入损失：

- 低置信或出界点；
- 与另一人同名点发生归属冲突、且没有明确匹配间隔的点；
- 被判定为遮挡或裁切的手臂/手部点；
- 会在两人之间产生歧义的点。

保留下来的点使用按人物尺度归一的鲁棒重投影损失。被冻结部位在梯度与参数更新两处都冻结，避免只靠零学习率的表面冻结。二维模型置信度只代表观测权重，不被解释为解剖可见性真值。

总目标分为独立记录的四组，而不是只保存一个加权和：

- 可见点鲁棒重投影；
- 相对 MultiHMR 初值的姿态、root 和平移正则；
- 双人有符号穿透；
- 数值与运动学可行性，包括正深度、有限参数和冻结部位不变。

首版不使用全身最近点吸引，也不从二维推断强制接触。正常靠近不惩罚，只有位于另一人体内部的表面才产生穿透损失，以免把拥抱推开。

## 7. 有符号穿透量尺与损失

无符号最近距离无法区分接触与穿透，不能作为本实验的主指标。Collision backend 对 A→B 与 B→A 两个方向执行查询：

1. Warp 在当前另一人网格上查询最近三角面、最近点、面符号与重心坐标。
2. 评测直接使用带符号距离：内部距离记为正穿透深度，外部记为零。
3. 优化时由 Torch 按查询面与重心坐标重组对应关系，计算当前查询点到目标表面的可微穿透项；查询对应按迭代刷新，目标面梯度采用半隐式处理。
4. 两个方向都进入损失和指标，不能只测 A 是否进入 B 而漏掉 B 是否包住 A。

主穿透指标是每帧、双向、全部查询顶点的平均正穿透深度，未穿透顶点计零，再对帧做配对统计。辅助指标包括穿透顶点率、穿透顶点中的 p95 深度，以及最大穿透超过 5 mm 的帧比例。2 mm 作为穿透顶点计数的最小报告阈值，同时保留连续值，避免只靠阈值分桶。

量尺先用具有解析答案的球体做分离、相切和已知重叠测试，再用 SMPL-X 网格做双向符号、人工加深重叠和反向探针。人工增加重叠时指标与损失必须上升；把两人分开时必须归零。若量尺与解析结果或符号测试不符，停止 GPU 精修，不进入效果比较。

这里的指标是顶点—网格穿透近似，不宣称等价于完整三角形相交体积或服装级碰撞。

## 8. 四臂对照与逐帧接受

所有优化臂共享完全相同的自动选人结果，避免把选人收益误记到精修头上：

| 臂 | 二维精修 | 穿透项 | 用途 |
|---|---|---|---|
| selected-init | 关 | 关 | 自动选人后的基线 |
| reproj-only | 开 | 关 | 测量二维监督本身是否加深穿透 |
| collision-only | 关 | 开 | 测量仅消除穿透的代价 |
| joint-full | 开 | 开 | 完整方案 |

每次迭代都保存分项指标。导出采用可行集选择而不是仅看总 loss：穿透必须下降，可见点重投影不得超过所选初值（只允许浮点容差），冻结部位和漂移预算必须满足；在满足条件的迭代中选穿透最低者。没有合格迭代时导出所选初值并记录 `no_improving_iterate`，不能把最后一次优化直接当结果。

## 9. 独立评测与通过条件

评测沿用现有 benchmark 的具名 body-12、逐人框对角线归一、漏人计入分母和演员组 cluster bootstrap 原则，并补充真实穿透指标。至少报告：

- 127 帧状态全覆盖、有效双人输出覆盖率、候选选择失败数；
- 二维 PCK@0.05/0.1、root MPJPE、absolute MPJPE、两人髋距向量误差；
- 平均正穿透深度、穿透顶点率、p95 深度、超过 5 mm 的帧比例；
- separated/light/hug/severe 分场景与 train/val/test 分组结果；
- 四臂在完全相同帧集合上的配对差和演员组 bootstrap 95% 区间。

通过条件同时包含效果、非劣效和覆盖。以下差值统一定义为 `joint-full − selected-init`，区间均为演员组 cluster bootstrap 95% 区间：

1. 平均正穿透深度差的区间上界必须小于 0，即完整臂取得统计上可分辨的穿透下降。
2. root/absolute MPJPE 与髋距向量误差差的区间上界均不得超过 +5 mm；PCK@0.1 差的区间下界不得低于 −0.005。超出边界则只保留实验结论，不接生产。
3. 完整臂的有效双人输出覆盖率不得低于 `selected-init`，且两者都以 127 为明确分母；若自动选人自身未达到原始至少两候选的 125/127，上界差距必须逐帧解释，不能宣称全 benchmark 通过。
4. `reproj-only` 与 `collision-only` 必须同时公开，用于解释残差和权衡；只报告完整臂不算完成验证。
5. 量尺反向探针、人物交换反例、缺失候选反例和重复实例反例全部通过，否则效果数字无效。

样本量不足以给出稳定区间时，结论写“指标功效不足”，不把点估计改善写成确定胜出。

## 10. 错误处理与复现

- 输入、模型缓存、SMPL-X 资产或 Warp 后端缺失时启动失败，不静默换成猜相机或空网格。
- 每帧异常写状态与错误，进程继续处理其他帧，但最终汇总必须保留失败分母。
- 每帧参数重新送入同一 SMPL-X 层，验证顶点、关节和投影。**2026-11-03 实施校准（用户已批准修订）**：冻结 pkl 未保存 MultiHMR 预测的 `expression`，且原始输出经过 autocast；实测原始 MultiHMR SMPL_Layer 反解 expression 后 body-12 三维误差可到 0，但完整网格和全关节投影分别残留约 0.488 mm 与 0.595 px，因此原定的全网格 `1e-4 m`、全关节 `0.25 px` 不适用于这份输入。修订后使用原始 MultiHMR SMPL_Layer + autocast 反解并冻结 expression，body-12 三维保持 `1e-4 m` 硬门，body-12 按原模型空间投影再逆仿射的路径保持 `0.25 px` 硬门；完整网格、全部 127 关节三维和全部 127 关节投影的输入数值残差必须全量记录。实际校准：train/val 101 个入选帧、202 个候选，body-12 残差 p100 为 `0.0009765625 m / 0.952392578 px`，按 `×1.1` 向上取整得到 `0.0011 m / 1.1 px`；test 不参与定门，不再宣称满足原全量阈值。可微 float32 导出仍须通过同一路径 round-trip 的 `1e-4 m / 0.25 px` 一致性检查。
- 产物使用独占创建或临时文件加原子改名，默认不覆盖；配置、代码、输入与输出记录 SHA256。
- GPU 作业串行，先小样 pilot，再扩大；不与计时/显存对照并发，不修改共用模型代码与既有结果。

## 11. 完成定义与后续决策

首版完成意味着：自动选人和四个对照臂在冻结清单上跑完，所有状态与覆盖率可审计，穿透量尺通过解析与反向测试，独立评测产出分场景配对结果，并生成至少覆盖 separated、hug、severe 的双色网格前后对照。

若完整臂满足穿透改善和非劣效门，再讨论普通单图、多视角接触、时间一致性和服装级碰撞。若只减少穿透却破坏双人位置，优先修正联合约束，不用更大的排斥权重继续推人；若自动选人成为主要错误来源，则先停止精修扩展，回到检测与实例归并。
