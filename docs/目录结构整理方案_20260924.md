## 6. 执行规程（每批次都必须遵守）

1. **同分区 `mv`**，禁止跨分区 `cp`（远端 `/` 仅剩 34 G）。
2. **单批 ≤ 10 个文件**，每批结束后核对，失败立即停止并回报。
3. 批次间**重新核验磁盘现状**（存在并发会话，不能依赖几分钟前的扫描结果）。
4. 被 git 跟踪的文件用 `git mv` 保留历史；被 gitignore 排除的用普通 `mv`。
5. 每个批次前打回滚点（tag 或 commit），保证可单批回退。
6. **删除类操作逐项确认**，不批量静默删除。
