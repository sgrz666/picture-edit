# V5固定样本实验结果报告工具

报告只读取TikTok与Hi4D已有的图片、配置、提交记录和审计结果，不构建模型、不读取权重张量、不生成图片、不调用optimizer。生成器给每组图片标明实验目的，保留每30步过程、GT、未训练观察帧和固定ROI细节。

## 工具与输入

- `scripts/audit/summarize_qwen21_fixedpair_training.py`：CPU核对300步提交谱系、阶段预算、冻结摘要和AdamW计数连续性；导出已提交的观察指标与生成记录。它需要读取训练快照元数据及CPU张量，但不运行模型。
- `scripts/reports/export_qwen21_fixedpair_report.py`：核对原始图片SHA、局部ROI与提交日志绑定，复制只读证据包。`--require-complete`要求两套300步、每30步图、最终种子、关闭对照和完成审计齐全；不齐全时拒绝最终导出。
- `scripts/reports/build_qwen21_fixedpair_visual_report.py`：离线生成单文件HTML、裁切来源和报告清单；`--review`接收复查真实图像后撰写的观察结论。正式报告不使用`--draft`。
- `scripts/reports/render_qwen21_fixedpair_report.cjs`：离线浏览器验证所有图片解码、页面无横向溢出、原图放大可用，再导出PDF和逐节截图。网络请求被禁止。

远端实验根目录分别为：

```text
/data/shangguanrz/pic-edit-experiments/qwen21_full_native_v1/tiktok-fixedpair-v5_20261025_v1
/data/shangguanrz/pic-edit-experiments/qwen21_hi4d_dual/hi4d-fixedpair-v5_20261025_v1
```

证据包中的`manifest.json`记录每张原图的完整SHA、尺寸、用途、远端路径，以及逐样本原始提示词。`evidence/`保存配置、数据／梯度报告和完成审计。`assets/`保留原文件字节；局部裁切另外存放，不修改原图。

## 生成与复查

先用既有审计工具对每个根目录生成新的`completion_audit_*.json`，再导出到双人实验族下的新版本目录。不要覆盖已经存在的报告目录。

```bash
python scripts/reports/export_qwen21_fixedpair_report.py \
  --output /data/shangguanrz/pic-edit-experiments/qwen21_hi4d_dual/hi4d-fixedpair-v5_20261025_v1/report/visual_evidence_20261026_v1 \
  --require-complete

python scripts/reports/build_qwen21_fixedpair_visual_report.py \
  --evidence <证据包目录> --output <新的报告目录> \
  --review <人工复查结论JSON>
```

本地PDF导出使用Codex提供的Node包目录和已经存在的Chromium，不安装浏览器或依赖：

```powershell
$env:CODEX_NODE_PACKAGES='<bundled node_modules绝对路径>'
$env:CODEX_REPORT_CHROMIUM='<已有chrome.exe绝对路径>'
$env:CODEX_REPORT_PYTHON='<bundled python.exe绝对路径>'
& '<bundled node.exe绝对路径>' scripts/reports/render_qwen21_fixedpair_report.cjs `
  '<报告HTML>' '<新的QA目录>'
```

PDF导出后必须渲染为PNG，检查分页、图片、中文和表格。浏览器结构检查不能代替视觉复查。最终报告目录包含HTML、PDF、`report_manifest.json`与独立来源清单；大文件不进入Git。

## 如何理解各组结果

E1为TikTok训练帧0374，E2为未训练观察帧0126；E3为Hi4D训练击掌帧000082，E4为未训练非接触帧000112。它们分别回答单样本拟合和同场景另一姿态响应问题，不回答跨人物泛化。

C1比较同输入的Qwen-only、V5初始化与300步；C2展示每30步变化；C3仅改变最终推理seed；C4关闭同一checkpoint的一种控制组合。C4不是独立训练消融，像素变化大小不等于质量好坏。

S0过程图只开启基础Body，后续阶段开启了局部路径；不能把跨阶段差异全部归因于训练步数。Local off关闭Face、Hand、Source Detail，但全身Identity仍保留；Depth off只关闭Depth融合，Body21、Owner及关系几何仍保留。

所有脸手裁切共用目标条件ROI，不对生成结果分别检测或修正位置。GT仅为监督／对照，目标RGB不进入生成外观接口。原始帧本身可能含运动模糊，应分别判断目标复现与静态清晰度。
